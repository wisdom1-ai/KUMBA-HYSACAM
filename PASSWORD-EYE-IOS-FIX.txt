PASSWORD EYE / IOS KEYBOARD FIX

The password eye keeps the input's native type=password at all times.
It reveals characters using CSS -webkit-text-security instead of changing the input to type=text.
This avoids the input-type transition that was changing the iPhone keyboard state when the eye was tapped.
The eye icon remains functional.
No Supabase credentials, database schema, authentication API, administrator role checks, or map files were changed.

iOS owns its native Caps Lock indicator. This change avoids causing a keyboard mode transition when the eye is tapped; it cannot hide an indicator caused by the user's actual Caps Lock state.
